# Screen setup

This screen is a setup preview. Its clinic tools are not available yet. Clinic sign-in and access checks must be configured before clinic data can be used here.

Use the navy rail to choose a workspace. In Settings, Admin, CRM and Notifications, expand a group in the second menu and select a page. The heading identifies your selected screen.

For Calendar, the Today status links select an appointment status filter. A dash in a status circle means counts are unavailable until appointments are connected.

Close help with Close help or Escape to return to the same screen. No entered form values or selected filters are changed by opening help. Each completed feature will supply its own instructions here.
