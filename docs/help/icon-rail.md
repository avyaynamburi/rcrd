# Main navigation

Use the navy rail on the left to open Dashboard, Calendar, Patients, Reports,
Admin, CRM and Help. Notifications, WhatsApp and Settings appear below the gap.
The current screen has an orange icon. Use Tab and Enter to navigate by keyboard.
The version number appears at the bottom.

The connection dot is green when the Rcrd server responds, red when it cannot be
reached, and grey while checking. Its accessible label also describes the state.
This checks the app server, not database or messaging provider availability.

A notification count appears only when there are unread notifications. The New
tag on WhatsApp means messaging needs setup or attention; no messages are sent
by the construction preview.

The public construction preview contains no clinic records. Tools show an
unavailable message until implemented. User and Logout controls are disabled
until sign-in is configured. Authenticated navigation must receive the user's
permitted destinations; server permission checks still protect every operation.
