# How to create an Rcrd shortcut

Install Rcrd using Chrome or Edge on Windows or Mac. Open the Rcrd HTTPS address in a normal browser window (localhost also works for development).

## Chrome

Open the three-dot menu → Cast, save and share → Install page as app. Confirm Install. An install icon may also appear in the address bar.

## Edge

Open the three-dot menu → Apps → Install this site as an app. Confirm Install. An install icon may also appear in the address bar.

## Open and manage the window

Open the installed shortcut from your desktop, Windows Start menu or Mac Applications folder. Rcrd opens in its own window without a browser bar, showing the Rcrd logo and name. Your operating system provides minimise, restore and close controls. Save your work before closing.

## If installation is unavailable

Browser labels vary. Update Chrome or Edge and check that the address uses HTTPS. If already installed, use the existing shortcut. Managed clinic computers may require the administrator to enable installation. You can continue in a browser.

Installation does not store patient records offline. Clinic tools require an internet connection. Save your work before applying an update and reopen Rcrd afterwards; updates never reload your work automatically.
