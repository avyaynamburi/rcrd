# Today's status circles

The seven top-bar circles represent total today (navy), scheduled (grey), checked in (red), engaged (orange), checked out (green), missed (dark grey), and cancelled (light grey). Hover or focus a circle to read its status. Select it to open the matching Calendar Today filter.

The setup preview displays a dash, never a fabricated zero. Live counts need authenticated center access and the appointment store; these are not connected yet. The Calendar destination explains this unavailable state. The circle outline carries its status color; its name is available to assistive technology.

The clinic clock displays India time (Asia/Kolkata) by default and updates as minutes change. The clock accepts the clinic timezone when trusted center context is available. Narrow layouts omit the top-bar circles and clock until the responsive shell is built.
