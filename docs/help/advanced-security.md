# Advanced Security

Open Settings → Practice → Clinic → General Details. Advanced Security is currently unavailable. The disabled switch does not enable any protections and cannot be saved.

The planned setting requires a second verification step, shorter sessions and one active session per user. Inactivity sign-out is also required for every clinic, with a default of 30 minutes and an owner-adjustable limit. These controls are not enforced yet; do not assume a session will expire after inactivity. Passwords are handled by the authentication provider, and provider sign-in rate limits still apply.

Before clinic use, the owner must complete the authentication setup and have all advertised protections verified using synthetic accounts. No patient information or passwords should be shared to do this. The original system's Advanced Security behaviour still needs clinic confirmation.
