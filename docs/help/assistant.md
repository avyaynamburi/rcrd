# Rcrd Assistant

Use the round speech-bubble button at the bottom-right of the workspace to open the assistant panel. Close it with the Close assistant button or Escape; keyboard focus returns to the launcher.

The greeting's red close button hides the greeting for your user in this browser. Clearing browser storage resets it. If storage is unavailable, dismissal lasts until the page reloads.

The setup preview uses a separate preference identity. The assistant cannot accept messages or voice yet. Clinic sign-in, consent and an approved India-resident provider must be connected in the AI phase. No patient information should be entered in the preview.
