# Help articles

One markdown file per screen, named by its help key (e.g. `calendar.md`, `settings-clinic.md`, `admin-payment-made.md`). Each screen's "Need Help?" link opens its article; the help page (HELP-02) lists them in groups; the AI assistant answers how-to questions from them.

Format:

```
---
title: How to book an appointment
group: Getting Started | FAQs | Clinic Setup Essentials | Features
features: [CAL-25, CAL-26]
---
Short steps in plain language. Name buttons exactly as they appear on screen.
```

Required early articles (from HELP-02): Quick Patient Journey, New WhatsApp activation, Basic Setup (Settings), How to create Rcrd shortcut, WhatsApp messages are not going, How to send Bulk WA to patients, Unable to edit bill / unable to edit plan, Clinic & Preference Setting, How to add Doctor/Staff, Add Payment Modes, SMS & Email Settings.
