# Workspace setup

Rcrd is being set up. Clinic sign-in and patient tools will be added in later phases. No patient data is stored by this starter screen. Choose **Need Help?** on the workspace to read the setup notice.

## Create an Rcrd shortcut

In Chrome, open the browser menu → Cast, save and share → Install page as app. In Edge, open the browser menu → Apps → Install this site as an app. Confirm Install. Browser labels can vary; the address bar may also offer an install icon. Use the existing shortcut if already installed. The site needs HTTPS (or localhost for development).

Rcrd opens in its own window. Save your work before choosing **Apply update**, then reopen Rcrd. Updates never automatically reload a working page. Clinic tools require an internet connection; installation does not store patient records for offline use.

## Logout

Choose **Logout** in the navy rail. The Rcrd warning asks “Are you sure you want to logout?” Choose **No** or press Escape to return to your work. Keyboard focus starts on No and returns to Logout when the warning closes. **Yes** currently reports that sign-in is not configured; it does not end a session or leave the page. Session sign-out will be connected when clinic login is implemented (ACC-02).

## Using the top bar

The white bar above the workspace shows the organisation display name in navy capital letters. “Clinic not configured” is the setup preview: no clinic identity has been connected yet.

Forms and patient profiles will use a Back link before the name to return to their parent screen. Calendar controls will occupy the right side on the calendar; status counts and date/time will occupy it on other clinic screens as those features are built. No counts are fabricated in the preview.

Open **Need Help?** from the workspace for this guidance under “Using the top bar”.

## Using the second menu

Settings, Admin, CRM and Notifications open a white menu beside the navy rail.
Select a group heading to open or close its pages. Several groups can stay open.
Select a page to open it; the current page has an orange marker and darker orange text.
Use Tab to reach headings and links, Enter to select, or Space to toggle a group.

Open groups are remembered in this browser for each account. The construction
preview uses a separate preview identity until sign-in is connected. Blocking
browser storage does not prevent navigation, but preferences will not survive a reload.
On narrow screens the menu sits above the work area. Need Help? opens workspace guidance.

These are navigation previews; clinic tools and clinic records remain unavailable until implemented and authorized.

## Reading screen help

Select the orange Need Help? control to open instructions beside your current screen. Close help or press Escape to return to the same place. Help can be scrolled independently. If an article is unavailable, close help and retry later.


## Colour meanings

Navy marks headings, the navigation rail and main buttons. Orange marks the selected navigation item and Need Help?; on white, text uses a darker orange for readability.

Green means Yes, checked out or connected. Red means No, checked in or an amount owed. Always read the accompanying status word, icon or accessible label: colour alone does not tell the full story. Appointment cards use the configured doctor or treatment-category colour; the default is pink. Light peach marks today's calendar column. Calendar and billing tools will use these colours as they become available.

Status-circle outlines distinguish scheduled (grey), checked in (red), engaged (orange), checked out (green), missed (dark grey) and cancelled (light grey). Each circle has a named tooltip and an accessible label. A dash means counts are unavailable, not zero.

## Success and error messages

Notifications appear at the bottom right, above the assistant button. Green messages marked Success confirm completed work. Red messages marked Error explain why an action could not finish. Read the reason before trying again; an error never means your work was saved.

Success messages close after eight seconds. Point at a message or focus its dismiss button to keep it open. Errors stay until you choose Dismiss notification. Messages remain while moving between workspace pages, but are cleared by a full reload. They are not a permanent record. The setup preview reports missing sign-in when you confirm Logout; it does not claim to sign you out.

## Phone and tablet navigation

Below 768 pixels wide, use the bottom bar for Dashboard, Calendar and Patients. More opens the remaining tools, account menu, Logout, connection status and app version. Choose Close navigation, tap outside or press Escape to dismiss it. At wider tablet sizes the left rail remains available. Settings and other second menus stack above the page on small screens.

The current setup preview contains no clinic records. Once clinic sign-in is available, phone access will require Enable Mobile Access in your account permissions. Forms will use one column and data tables will use labelled cards on narrow screens as those clinic screens are built.
